CSS Grid sirve para organizar elementos en **filas y columnas**. Es especialmente útil cuando quieres controlar ambas dimensiones, como en una galería de tarjetas o en la estructura de una página. En esta guía vas a construir un ejemplo que puedes copiar y adaptar.

## Activar Grid

Solo necesitas una línea:

```css
.container {
  display: grid;
}
```

## Definir columnas y filas

Estas alternativas muestran distintas formas de definir las columnas; usa **una** declaración de `grid-template-columns` a la vez:

```css
.container {
  display: grid;

  /* Tres columnas iguales */
  grid-template-columns: repeat(3, 1fr);
}
```

Si necesitas una columna lateral fija y otra flexible, cambia esa línea por `grid-template-columns: 200px minmax(0, 1fr)`. También puedes definir alturas explícitas con `grid-template-rows`, aunque muchas veces conviene dejar que el contenido determine la altura de cada fila.

## La unidad `fr`

`fr` significa «fracción del espacio disponible» **después** de descontar tamaños fijos y espacios como `gap`:

```css
.container {
  /* La segunda columna es el doble de ancha */
  grid-template-columns: 1fr 2fr 1fr;
}
```

## Espacio entre elementos (gap)

```css
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  
  /* Espacio entre filas y columnas */
  gap: 20px;
  
  /* O por separado */
  row-gap: 20px;
  column-gap: 10px;
}
```

## Grid responsivo automático

Para una galería de tarjetas que se adapte al ancho disponible, combina `repeat()`, `auto-fit` y `minmax()`:

```css
.container {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 250px), 1fr));
  gap: 20px;
}
```

Cada columna intenta medir al menos **250px**, pero `min(100%, 250px)` le permite reducirse si el contenedor es más estrecho. El máximo `1fr` reparte el espacio sobrante. `auto-fit` compacta las columnas vacías, de modo que las tarjetas presentes pueden ocupar el ancho disponible. Esta técnica evita una media query para **esta galería**; no elimina la necesidad de media queries en todos los layouts.

## Ejemplo propio: tarjetas de artículos

Este HTML y CSS forman una galería completa. Coloca el HTML en una página y el CSS en su hoja de estilos o dentro de una etiqueta `<style>` para probarlos:

```html
<section class="articulos" aria-label="Artículos recientes">
  <article class="articulo">
    <h2>Aprende CSS Grid</h2>
    <p>Organiza contenido en filas y columnas.</p>
  </article>
  <article class="articulo">
    <h2>Aprende Flexbox</h2>
    <p>Alinea elementos en una sola dirección.</p>
  </article>
  <article class="articulo">
    <h2>Diseño responsivo</h2>
    <p>Adapta la interfaz al espacio disponible.</p>
  </article>
</section>
```

```css
.articulos {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 250px), 1fr));
  gap: 1rem;
}

.articulo {
  min-width: 0;
  padding: 1.5rem;
  border: 1px solid #d1d5db;
  border-radius: 0.75rem;
}
```

Al estrechar la ventana, las tarjetas pasan de varias columnas a una sin cambiar el HTML. El `min-width: 0` permite que el contenido del artículo se reduzca dentro de su celda; si incluyes una URL o una palabra muy larga, añade `overflow-wrap: anywhere` al elemento de texto que la contiene.

## Posicionar elementos

Puedes controlar dónde va cada elemento:

```css
.item {
  /* Empieza en línea 1, termina en línea 3 */
  grid-column: 1 / 3;
  
  /* Abreviatura: ocupa 2 columnas */
  grid-column: span 2;
  
  /* Lo mismo para filas */
  grid-row: 1 / 2;
}
```

## Ejemplo: Layout de página completa

```css
.page {
  display: grid;
  grid-template-columns: 250px minmax(0, 1fr);
  grid-template-rows: auto 1fr auto;
  min-height: 100vh;
}

.header {
  grid-column: 1 / -1; /* Ocupa todo el ancho */
}

.sidebar {
  grid-row: 2;
}

.main {
  grid-row: 2;
}

.footer {
  grid-column: 1 / -1;
}

/* En pantallas estrechas, la barra lateral pasa arriba del contenido */
@media (max-width: 700px) {
  .page {
    grid-template-columns: minmax(0, 1fr);
  }

  .header,
  .footer {
    grid-column: 1;
  }

  .sidebar,
  .main {
    grid-row: auto;
  }
}
```

Aquí sí usamos una media query: una barra lateral fija de 250px no siempre cabe junto al contenido principal. En una pantalla estrecha, la cuadrícula se convierte en una sola columna.

## Errores comunes al empezar

- **Aplicar `grid-column` al contenedor:** esta propiedad posiciona un *elemento hijo* dentro de la cuadrícula. En el contenedor defines columnas, filas y `gap`.
- **Usar `1fr` y ver que una columna se desborda:** el contenido puede imponer un ancho mínimo. Prueba `minmax(0, 1fr)` en la columna flexible y `min-width: 0` en el elemento hijo cuando necesites que se reduzca.
- **Fijar 250px como mínimo en una pantalla más estrecha:** `minmax(250px, 1fr)` no puede bajar de 250px. Para tarjetas, `minmax(min(100%, 250px), 1fr)` evita ese desbordamiento.
- **Esperar que Grid reorganice el significado del contenido:** el orden visual no reemplaza al orden lógico del HTML. Escribe primero un documento que tenga sentido al leerse de arriba abajo.

## Cheatsheet rápido

| Propiedad | Qué hace |
|-----------|----------|
| `display: grid` | Activa grid |
| `grid-template-columns` | Define columnas |
| `grid-template-rows` | Define filas |
| `gap` | Espacio entre elementos |
| `grid-column` | Posición horizontal del item |
| `grid-row` | Posición vertical del item |
